# Data provenance and licences — `fixtures/bench/`

Two kinds of fixture live here, under two different licences. The split
matters because one of them carries obligations.

## Original synthetic fixtures — Apache-2.0, same as the code

Hand-authored or generated by `scripts/make-synthetic-area.ts`. Fake
coordinates, fake names, no upstream source. Yours to reuse under the
repository licence:

- `synthetic-pacific.geojson`
- `synthetic-expansion.geojson`
- `synthetic-heat.geojson`
- `synthetic-diff-a.geojson`
- `synthetic-diff-b.geojson`

## OpenStreetMap-derived fixtures — ODbL 1.0

Recorded from Overpass API responses by `scripts/capture-overpass-fixtures.ts`
and `scripts/capture-bench-areas.ts`. The geometry, tags and names are
© OpenStreetMap contributors, available under the Open Database Licence
(ODbL 1.0, https://opendatacommons.org/licenses/odbl/).

What that obliges, in plain terms:

- **Attribute.** Any public use of these files or numbers derived from them
  credits © OpenStreetMap contributors.
- **Share-alike covers the database.** These fixture files are a derived
  database: redistribute them (or a modified version) under ODbL, not under
  Apache-2.0. The Apache licence on the repository covers the code and the
  synthetic fixtures above — it does not and cannot relicense OSM data.
- **Produced works** (maplets rendered from the data, benchmark scores,
  model answers archived in `bench-results/`) carry the attribution
  requirement but not share-alike. Citing a score computed over sf-cbd needs
  the © credit line, not a licence change.

## Why this file exists

The ODbL question sat open as datasheet §13 item 5, flagged as "assumed, not
answered". This file is the answer: checked per file, not assumed per repo.
