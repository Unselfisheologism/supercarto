Navigate to the release assets and grab `supercarto-0.6.2.mcpb` (384 KB). Open it with Claude Desktop and the maps tools install: the server runs from the bundle as a plain Node process with zero npm dependencies, so the only requirement on the machine is Node >= 18.

Alongside the always-on tools `get_maplet`, `localize`, `route`, `search_places`, `expand_feature`, `get_terrain`, `get_weather`, `get_daylight`, the install-time configuration can wire `get_traffic` (needs a routing-provider key) and `get_transit` / `get_transit_route` (needs a local GTFS feed path, plus the operator's GTFS-Realtime TripUpdates URL for live per-trip delay lines).

Optional install config:
- an Open-Meteo API key for higher weather rate limits
- a GTFS feed path (directory of .txt tables or a .zip)
- the feed operator's TripUpdates URL

The manifest marks the tool catalog as generated, mirroring the server's own honest-refusal design: whatever answers introspection is exactly what that installation can answer. Verified with the official `mcpb validate` CLI and an unpacked-bundle initialize probe.
