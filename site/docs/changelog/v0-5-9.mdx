No code change. Carries the ownership markers the official MCP registry verifies: `mcpName` in the npm manifest, an `mcp-name:` comment in the README that ships to PyPI, `server.json` (npm + PyPI publications, stdio), and `publish-mcp.yml`, which publishes to registry.modelcontextprotocol.io with GitHub OIDC after npm carries the tag. Adds a Dockerfile with an initialize/introspection probe for registry health checks (Glama et al.).
