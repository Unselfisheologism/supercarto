Bug fixes:

- Live Overpass fetch now works for negative latitudes: supercarto emits the positional (s,w,n,e) bbox form instead of the bbox:-prefixed form, which the public Overpass instance rejects with HTTP 400 for negative-latitude boxes. Includes a regression test.
- Connectivity fixes for token-budgeted map graphs (PR #1, fix-connected-budget).

No new features. Full details in CHANGELOG.md.
