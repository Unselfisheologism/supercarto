New `get_transit` tool over any static GTFS feed (dir or .zip via `SUPERCARTO_GTFS`): stops, lines, and first/last departures for the queried day, with three honest service states (running / none / unknown), past-midnight times kept as recorded (`25:10`), straight-line distances labelled, and a hard re-measured token budget with connection-preserving pruning.

Fixed: slope heat layers no longer vanish when every surviving hotspot ties (uniformly steep terrain is a fact, not an absence) — compiler change mirrored in the Python port and parity-checked.

412 tests passing; verified against the GTFS sample feed in all three service states. Apache-2.0.
