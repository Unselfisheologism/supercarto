- **Fix:** `get_transit` (MCP, HTTP, CLI) fetched the realtime overlay but never joined it — a deployment with `SUPERCARTO_GTFS_RT` set answered schedule-only, silently. Now every public entry point joins predictions, as 0.5.4 intended and its tests (which bypassed the public path) believed had shipped.
- The `TransitSource` interface now carries the overlay parameter, so this bug class fails type check next time. Two regression tests pin the wire itself.
